    2.3 Methods
    
      
    Angles: θ = 180° − ∠(proximal, distal) at each joint, from the world landmarks (hand model) or the marker centroids (side view). Zeroing: θ ← θ − median(θ) over the last second of the rest phase, provided P90 − P10 ≤ 5° there; otherwise P2 of the take. Filtering: Savitzky–Golay, window 11, order 3 (zero phase). ROM = P95(θ) − P5(θ). ωpeak = P95|dθ/dt|. Cycles: peaks of prominence ≥ 0.35·ROM. Onset: first t with |ω| > 30°/s for 3 consecutive samples. Lag = arg maxτ Rxy(τ), |τ| ≤ 1 s (5 s for the follower). Accuracy = 1 − RMSE/ROM. Slower = 1 − ωpeak,worn/ωpeak,bare. Settle: first t after GO with |θ − target| ≤ 4° held 0.3 s.
